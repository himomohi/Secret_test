게임 데이터 파일을 생성해주세요.

## 데이터 타입

### 1. 캐릭터/직업 데이터
최소 5개 이상의 고유한 캐릭터를 만들어주세요:
- 이름, 설명
- 기본 스탯 (체력, 공격력, 속도, 방어력 등)
- 시작 스킬
- 고유 능력/보너스
- 비주얼 정보 (색상, 크기 등)

### 2. 스킬 데이터
다양한 스킬을 최소 20개 이상 만들어주세요:
- 투사체 스킬
- 근접 공격 스킬
- 범위 공격 스킬
- 버프/디버프 스킬
- 소환 스킬
- 특수 스킬

각 스킬 포함 사항:
- 이름, 설명, 타입
- 피해량, 쿨다운
- 속도, 범위, 지속시간
- 특수 효과

### 3. 아이템 데이터
최소 30개 이상의 아이템:
- 무기 (10개)
- 방어구 (10개)
- 악세서리 (10개)
- 소모품 (10개)

각 아이템 포함 사항:
- 이름, 설명, 타입, 희귀도
- 스탯 보너스
- 특수 효과
- 비주얼 정보

### 4. 적 데이터
최소 10개의 적 타입:
- 기본 적 (5개)
- 엘리트 적 (3개)
- 보스 (2개)

각 적 포함 사항:
- 이름, 체력, 공격력
- 이동 속도, 크기
- AI 패턴
- 드롭 아이템
- 경험치/점수

## 데이터 구조
JavaScript 객체 배열로 구현:
```javascript
const CHARACTERS = [
    { id: 'warrior', name: '전사', ... },
    ...
];
```

## 밸런싱
- 초반 캐릭터는 쉽게
- 후반으로 갈수록 난이도 증가
- 다양한 플레이 스타일 지원
- 시너지 효과 고려

창의적이고 재미있는 데이터를 만들어주세요!
