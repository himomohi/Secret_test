- [ ] 더티 렉트 렌더링
- [ ] 스프라이트 배칭

### 2. 업데이트 루프 최적화
- [ ] 오브젝트 풀링 시스템
- [ ] 공간 분할 (Quadtree, Grid)
- [ ] 업데이트 우선순위 시스템
- [ ] 프레임 스킵 처리

### 3. 메모리 최적화
- [ ] 불필요한 객체 생성 제거
- [ ] 배열 재사용
- [ ] 메모리 누수 확인
- [ ] 가비지 컬렉션 최소화

### 4. 데이터 구조 최적화
- [ ] 배열 vs Set/Map 선택
- [ ] 정렬 알고리즘 최적화
- [ ] 캐싱 전략

### 5. 충돌 감지 최적화
- [ ] 광역 판정 (Broad phase)
- [ ] 세밀 판정 (Narrow phase)
- [ ] 공간 분할 활용

## 성능 측정
- FPS 카운터 추가
- 프로파일링 포인트 추가
