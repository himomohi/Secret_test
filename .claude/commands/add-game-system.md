현재 게임 프로젝트에 새로운 시스템을 추가해주세요.

## 시스템 타입
다음 중 하나를 선택하거나 새로운 시스템을 제안하세요:

1. **충돌 감지 시스템** (CollisionSystem)
   - AABB, 원형, 폴리곤 충돌 감지
   - 공간 분할 최적화
   - 충돌 이벤트 핸들링

2. **파티클 시스템** (ParticleSystem)
   - 파티클 생성 및 관리
   - 이펙트 프리셋
   - 성능 최적화

3. **사운드 시스템** (AudioSystem)
   - 사운드 효과 재생
   - 배경 음악 관리
   - 볼륨 조절

4. **저장/로드 시스템** (SaveSystem)
   - LocalStorage 기반 저장
   - 게임 상태 직렬화/역직렬화
   - 자동 저장

5. **스폰 시스템** (SpawnSystem)
   - 적/아이템 스폰 관리
   - 난이도 조절
   - 웨이브 시스템

6. **퀘스트 시스템** (QuestSystem)
   - 퀘스트 관리
   - 진행 상황 추적
   - 보상 시스템

## 구현 요구사항
- 기존 게임 엔진과 통합
- 깔끔한 API 디자인
- 성능 최적화
- 문서화된 코드

사용자가 원하는 시스템을 구현하세요.
