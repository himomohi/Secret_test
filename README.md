# 🧛 Vampire Survivors Clone - Pixel Edition

뱀파이어 서바이벌 스타일의 픽셀 아트 로그라이크 서바이벌 게임

## ✨ 주요 기능

### 🎮 게임플레이
- **12개의 고유한 캐릭터/직업** - 각각 다른 능력치와 시작 스킬
- **110개 이상의 스킬** - 투사체, 근접, 오라, 소환 등 다양한 타입
- **125개 이상의 아이템** - 무기, 방어구, 악세서리, 소모품
- **랜덤 맵 생성** - 매 게임마다 다른 맵 (벽, 나무, 방 시스템)
- **자동 저장 시스템** - LocalStorage를 사용한 진행 상황 저장

### 🎨 디자인
- 깔끔한 픽셀 아트 스타일
- 픽셀 퍼펙트 렌더링
- 다양한 시각 효과
- **완전 반응형** - 모든 화면 크기 지원

### 🎯 게임 시스템
- 레벨업 시 스킬 선택
- 시간에 따른 난이도 증가
- 다양한 적 타입 및 보스
- 아이템 수집 및 캐릭터 강화
- 실시간 전투 시스템

### 📱 모바일 지원
- **완벽한 모바일 최적화** - 스마트폰, 태블릿 지원
- **터치 컨트롤** - 가상 조이스틱으로 쉬운 조작
- **반응형 UI** - 화면 크기에 자동 최적화
- **성능 최적화** - 모바일 환경에서도 60 FPS

## 🕹️ 조작법

### 데스크톱
- **WASD** 또는 **방향키**: 이동
- **ESC**: 일시정지/메뉴
- 공격은 자동으로 실행됩니다

### 모바일
- **가상 조이스틱** (화면 왼쪽): 캐릭터 이동
- **일시정지 버튼** (화면 오른쪽 하단): 게임 일시정지
- 공격은 자동으로 실행됩니다

## 🎭 캐릭터

1. **전사** - 높은 체력과 방어력
2. **마법사** - 강력한 마법 공격
3. **궁수** - 빠른 원거리 공격
4. **암살자** - 치명타 특화
5. **성기사** - 방어와 치유
6. **네크로맨서** - 언데드 소환
7. **광전사** - 공격적인 근접 전투
8. **드루이드** - 자연 마법
9. **수도승** - 빠른 연속 공격
10. **원소술사** - 모든 원소 마법
11. **소환사** - 다양한 소환수
12. **엔지니어** - 기계 장치 설치

## 🏗️ 기술 스택

- **순수 JavaScript (ES6+)** - 프레임워크 없이 구현
- **HTML5 Canvas** - 픽셀 퍼펙트 렌더링
- **LocalStorage API** - 게임 저장
- **Touch Events API** - 모바일 터치 입력
- **Responsive Design** - 완전 반응형 레이아웃

## 🚀 실행 방법

### 빠른 시작 (모든 플랫폼)
1. 이 저장소를 클론하거나 다운로드
2. `index.html` 파일을 브라우저에서 열기
3. 또는 GitHub Pages에서 플레이: [Live Demo](#)

### 모바일에서 플레이
1. 스마트폰 브라우저에서 접속
2. 전체 화면으로 플레이 권장
3. 가로/세로 모드 모두 지원
4. 홈 화면에 추가하여 앱처럼 사용 가능

## 🎮 게임 팁

- 초반에는 투사체 스킬을 중심으로 수집하세요
- 체력 재생 아이템은 생존에 큰 도움이 됩니다
- 레벨업 시 이미 보유한 스킬을 강화할 수도 있습니다
- 시간이 지날수록 적이 강해지니 신중하게 스킬을 선택하세요
- 맵의 벽과 나무를 활용해 적의 이동을 제한하세요
